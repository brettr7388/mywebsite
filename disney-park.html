Disney Park Reservation System

A full‑stack app (Node.js/Express + React + MongoDB) letting users create & manage event reservations.

Features

  • Create & view event reservations
  • Responsive React.js frontend
  • Data persistence via MongoDB

Tech Stack

  • Node.js & Express
  • MongoDB & Mongoose
  • React.js frontend

How to Run Locally

  1. Clone repo:
    git clone https://github.com/brettr7388/disney-park-reservation.git
  2. Install deps:
    cd backend && npm install
cd ../frontend && npm install
  3. Start MongoDB (local or cloud) and update `.env` connection string.
  4. Run servers:
    cd backend && npm start
cd ../frontend && npm start
